# 🚪 Behind the Closed Door

**An interactive psychiatric nursing case study — Choose the Consequence.**

You are the nurse on duty. Adam, 32, is deteriorating, and every decision has a timer.
Right choices save the patient. Wrong choices make him worse, and you must intervene again.

## What it covers
- Seclusion and restraint: when they are justified, and when they are not
- Monitoring and complications (respiratory depression, restraint-related circulation injury)
- Reassessing and ending restrictive interventions
- Patient rights, dignity and ethics

## How it plays
1. A patient file opens with a live vitals monitor (HR, SpO₂, respiratory rate).
2. Each of the 5 decisions has a 20-second countdown.
3. Correct choice → the patient is saved and the case moves on.
4. Wrong choice (or running out of time) → the consequence is shown, the patient worsens, and a rescue decision follows.
5. A second wrong choice ends in an adverse outcome, and you retry from that decision.

## Run it
Open `index.html` in any browser. No install, no dependencies.
(Rename `behind-the-closed-door.html` to `index.html` to publish with GitHub Pages.)

## Disclaimer
Educational, hypothetical scenario. A psychiatric diagnosis does not make a patient dangerous.
Authorization, monitoring and documentation requirements vary by law and hospital policy;
always follow your course reference and local protocol.
